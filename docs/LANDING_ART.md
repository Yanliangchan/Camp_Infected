# Landing visual direction

The landing page now opens by default. Dark green, cream typography and warm amber accents frame the actual guardhouse scene. The copy establishes the Singapore-inspired camp setting, intended three-player online co-op and room-by-room encounter structure, with an explicit development-preview notice.

Explore the camp opens the first-room visual review. Meet the squad opens the soldier review. Neither button starts unfinished gameplay or sends a network request.

Presentation includes a slow camera drift, feathered dust, a subdued amber beacon, a dim security light sweep, intro transitions and button hover states. A persistent pause toggle stops scene movement and the CSS beacon animation. System reduced-motion preferences set this state automatically; the user can choose to resume. The scene has no rapid flashing or autoplay audio.

Verified with the production build, desktop 1280 x 720 and phone 390 x 844 visual review, both primary preview buttons, pause/resume and browser error logs. Gameplay is still awaiting visual approval. The separate room and character review controls remain available.
